## Codebase Patterns
- Package name for snapshot testing is `syrupy`, not `pytest-syrupy`
- All `__init__.py` files are empty placeholders
- CLI entry point: `asre.cli.main:cli` using Click
- mypy configured in strict mode in pyproject.toml
- pytest configured with testpaths = ["tests"] in pyproject.toml
- Test directories (tests/, tests/unit/, tests/integration/) need `__init__.py` files
- Use `from __future__ import annotations` in dataclass modules for `str | None` syntax
- Run tests with `python3 -m pytest` (not `python -m pytest`) on this system
