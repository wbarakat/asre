# Pipeline Overview

ASRE runs the following high-level flow:

1. Ingest
2. Canonicalize
3. Facility normalize
4. Stitch
5. Dedup
6. Reconcile
7. Score
8. Materialize
9. Quality check
10. Episode stitch
11. Episode materialize
12. Episode quality

Outputs are written to the warehouse on successful completion.
